### KRaft (Knowledge)

* **KRaft (Kafka Raft)** is the modern cluster management mode introduced to replace ZooKeeper.
* KRaft stores and manages **cluster metadata** (brokers, topics, partitions, leader information).
* KRaft uses the **Raft consensus protocol** to keep metadata consistent across the cluster.
* Modern Kafka clusters run **without ZooKeeper**.

---

## Controller vs KRaft

| Controller                                               | KRaft                                                                |
| -------------------------------------------------------- | -------------------------------------------------------------------- |
| **Controller is a role.**                                | **KRaft is a cluster management mode/protocol.**                     |
| Responsible for leader election and cluster management.  | Responsible for coordinating and maintaining cluster metadata.       |
| Only one active Controller exists at a time.             | KRaft is used by the entire cluster.                                 |
| A Controller runs **within KRaft mode** in modern Kafka. | KRaft provides the infrastructure that enables cluster coordination. |

---

## Remember ⭐

* **Controller = WHO manages the cluster.**
* **KRaft = HOW the cluster manages and agrees on metadata.**
* **Controller is a role inside a KRaft-based Kafka cluster, not a replacement for KRaft.**

This is beyond what your PDF explains, but it's useful background knowledge for understanding modern Kafka architecture.
