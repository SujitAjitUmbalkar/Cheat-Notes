# Apache Kafka 4.3.1 Setup Guide (Ubuntu WSL)

## Prerequisites

### 1. Install WSL (Windows)

Open PowerShell as Administrator:

```powershell
wsl --install
```

Restart your PC.

---

### 2. Install Ubuntu

Open Microsoft Store → Install **Ubuntu**

Launch Ubuntu and create

* Username
* Password

Example:

```text
Username : jeetu
Password : ********
```

---

### 3. Update Ubuntu

```bash
sudo apt update
```

---

### 4. Install Java 21

```bash
sudo apt install openjdk-21-jdk -y
```

Verify

```bash
java -version
```

Expected

```text
openjdk version "21.x.x"
```

# Download Kafka

Download Kafka 4.3.1

```text
https://kafka.apache.org/downloads
```

Download

```
kafka_2.13-4.3.1.tgz
```

Extract it on Windows.

Example

```text
Desktop
    kafka_2.13-4.3.1
```

# Generate Cluster ID

```bash

```

Example


# Format Kafka Storage

Kafka 4.x uses KRaft Mode.

Run

```bash
bin/kafka-storage.sh format \
--standalone \
-t <Cluster_ID> \
-c config/server.properties
```

Example

```bash
bin/kafka-storage.sh format \
--standalone \
-t FGPPjsgNSoCeRwPPGnknag \
-c config/server.properties
```

Expected

```text
Formatting dynamic metadata voter directory...
```

---

# Start Kafka Server

```bash
bin/kafka-server-start.sh config/server.properties
```

Expected

```text
Kafka Server started
```

Keep this terminal open.

# Create Topic

Open another Ubuntu terminal.

Go to Kafka directory.

```bash
cd ~/kafka_2.13-4.3.1/kafka_2.13-4.3.1
```

Create topic

```bash
bin/kafka-topics.sh \
--create \
--topic first-topic \
--bootstrap-server localhost:9092
```

Expected

```text
Created topic first-topic.
```

---

# Start Consumer

Open another terminal.

```bash
bin/kafka-console-consumer.sh \
--topic first-topic \
--from-beginning \
--bootstrap-server localhost:9092
```

Consumer waits for messages.

---

# Daily Commands

Start Kafka

```bash

```

Create Topic


List Topics

```bash
bin/kafka-topics.sh --list --bootstrap-server localhost:9092
```

Delete Topic

```bash
bin/kafka-topics.sh --delete --topic topic-name --bootstrap-server localhost:9092
```

Producer

## Important Note (Kafka 4.x)

Unlike Kafka 3.x tutorials, Kafka 4.x uses **KRaft mode by default**. During the first setup, storage must be formatted using:

```bash
bin/kafka-storage.sh format --standalone -t <Cluster_ID> -c config/server.properties
```

This is a one-time initialization step. After that, you only need to start the broker with:

```bash
bin/kafka-server-start.sh config/server.properties
```

You do **not** need to format the storage every time you start Kafka. This distinction is important for understanding Kafka 4.x and for interviews.
